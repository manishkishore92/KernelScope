# DTS Hardware Map

`kernelscope dts-map` creates a hardware-oriented map from DTS and DTSI files.

```bash
kernelscope dts-map ./kernel/xiaomi/sweet
```

It detects hints for display, touch, camera, battery, charger, regulators, GPIO, thermal zones, fingerprint, audio, Wi-Fi, Bluetooth, USB, storage, and other hardware areas.
